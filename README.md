# KMAC 네트워킹 데이 동선

NC AI 본사(1층 · 지하 1층 · 컨벤션홀)의 행사 동선을 3D로 보고 편집하는 단일 HTML 페이지입니다.

- **바로 열기:** `index.html`을 브라우저로 열면 됩니다 (3D 라이브러리를 CDN에서 불러오므로 인터넷 연결 필요).
- **GitHub Pages:** 저장소 Settings → Pages → Branch `main` / root 로 켜면 `https://ukiahptc.github.io/KMACnetworking/` 에서 열립니다.

## 기능
- 1층 / 지하 1층 / 컨벤션홀 내부 3개 화면 전환, 위에서 보기, 원본 도면 겹쳐 보기
- 동선 레이어(VIP · 회원사 네트워킹 · 전시·발표 · IR · 운영진) 표시/숨김
- 장소를 차례로 누르면 벽·폐쇄 구역을 피해 자동으로 이어지는 동선, 직접 그리기
- 장소 추가 · 이동 · 이름 변경
- 컨벤션홀 좌석 배치(직사각형 / 극장식 / 원탁 / 비움), 1800×600 테이블 아이콘 배치 · 360° 회전 · 겹침 방지
- 그린 내용은 브라우저에 저장되며, 데이터 내보내기 · 불러오기 지원

치수는 일부 실측값(출입문 간격 17 m, 뒤쪽 벽 2.15 m × 12칸)을 반영했고, 나머지는 도면과 현장 영상을 보고 추정한 약도입니다.
